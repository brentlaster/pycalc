# Calculator Application

This is a simple Python calculator application that supports basic arithmetic operations:
- Addition
- Subtraction
- Multiplication
- Division

## Functions

### `add(a: float, b: float) -> float`
Adds two numbers and returns the result.

### `subtract(a: float, b: float) -> float`
Subtracts the second number from the first and returns the result.

### `multiply(a: float, b: float) -> float`
Multiplies two numbers and returns the result.

### `divide(a: float, b: float) -> float | None`
Divides the first number by the second. Returns the result, or `None` if division by zero is attempted.
